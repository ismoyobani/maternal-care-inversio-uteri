# Maternal Care – Inversio Uteri

Modul pembelajaran keperawatan berbahasa Indonesia mengenai inversio uteri sebagai salah satu kegawatdaruratan obstetri pada maternal hemoragik.

## Materi
1. Pendahuluan: definisi, anatomi uterus, dan hubungan dengan kala III persalinan.
2. Konsep dasar: klasifikasi derajat dan waktu, etiologi, faktor risiko, serta diagnosis banding.
3. Patofisiologi: invaginasi fundus, gangguan kontraksi, perdarahan, dan syok.
4. Tanda, gejala, dan diagnosis: pengkajian, pemeriksaan klinis, penunjang, serta diagnosis banding.
5. Komplikasi akut dan lanjutan.
6. Prinsip penatalaksanaan kolaboratif dan eskalasi kegawatdaruratan.
7. Asuhan keperawatan: pengkajian, masalah keperawatan, luaran, intervensi, SBAR, evaluasi, dan dokumentasi.
8. Pencegahan, prognosis, dan edukasi pascakejadian.
9. Studi kasus pembelajaran.
10. Video pembelajaran dan referensi ilmiah.

## Fitur
- Navigasi materi per bagian.
- Tampilan responsif desktop dan ponsel.
- Dua video YouTube tertanam.
- Referensi medis dan pedoman eksternal.
- Tanpa kuis, backend, atau database; konten bersifat statis.

## Menjalankan lokal
Buka `index.html` melalui browser. Video dan tautan referensi memerlukan koneksi internet.

## Deploy
Situs statis. Pengaturan Vercel: framework preset **Other**, root directory `./`, build command kosong, output directory `.`.

## Catatan akademik dan keselamatan
Konten merupakan ringkasan edukasi, bukan protokol praktik klinis atau pengganti keputusan tenaga kesehatan. Validasi materi bersama dosen/pembimbing klinik dan sesuaikan dengan pedoman resmi, SDKI–SLKI–SIKI, kewenangan, serta SOP fasilitas kesehatan. Diagnosis dan tindakan definitif inversio uteri harus dilakukan oleh tim klinis kompeten.
