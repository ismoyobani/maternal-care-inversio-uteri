# Maternal Care – Inversio Uteri

Media pembelajaran keperawatan berbasis web mengenai inversio uteri pada maternal hemoragik.

## Fitur
- Materi: pendahuluan, konsep dan klasifikasi, patofisiologi, tanda dan diagnosis, prinsip penatalaksanaan, asuhan keperawatan.
- Studi kasus pembelajaran.
- Dua video YouTube tertanam.
- Referensi medis eksternal.
- Tampilan responsif untuk desktop dan ponsel.
- Tidak memakai kuis, backend, atau database.

## Menjalankan lokal
Buka `index.html` melalui browser. Video dan tautan referensi memerlukan internet.

## Deploy
Proyek berupa situs statis. Di Vercel gunakan framework preset **Other**, root directory `./`, build command kosong, dan output directory `.`.

## Catatan keselamatan akademik
Konten merupakan bahan ajar awal, bukan protokol klinis. Minta dosen/pembimbing klinik meninjau isi dan kesesuaiannya dengan SOP serta standar institusi sebelum digunakan secara resmi. Penanganan inversio uteri harus dilakukan oleh tim klinis kompeten.
